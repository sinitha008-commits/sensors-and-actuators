# Piezo Sensor with Arduino (Tinkercad)

## Overview

This project demonstrates how to interface a Piezo Sensor with an Arduino Uno in Tinkercad. A Piezo Sensor generates a small electrical signal when it is tapped, pressed, or vibrated. The Arduino reads this signal through an analog input and displays the sensor value on the Serial Monitor.

---

## Components Required

- Arduino Uno
- Piezo Sensor
- Breadboard
- Jumper Wires
- Tinkercad Circuits

---

## Circuit Connections

| Piezo Sensor Pin | Arduino Connection |
|------------------|-------------------|
| Positive (+) | A0 |
| Negative (-) | GND |

### Circuit Diagram

```
Piezo Sensor          Arduino Uno
--------------------------------
Positive (+) -------> A0
Negative (-) -------> GND
```

---

## Arduino Code

```cpp
const int piezoPin = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int sensorValue = analogRead(piezoPin);

  Serial.print("Piezo Value: ");
  Serial.println(sensorValue);

  delay(100);
}
```

---

## Knock Detection Code

```cpp
const int piezoPin = A0;
const int threshold = 100;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int sensorValue = analogRead(piezoPin);

  if(sensorValue > threshold) {
    Serial.println("Knock Detected!");
  }

  delay(50);
}
```

---

## Working Principle

1. The Piezo Sensor converts mechanical vibrations into electrical signals.
2. When the sensor is tapped or vibrated, it produces a voltage.
3. Arduino reads this voltage through analog pin A0.
4. The sensor value is displayed on the Serial Monitor.
5. If the value exceeds a threshold, a knock or vibration is detected.

## How to Run

1. Open Tinkercad Circuits.
2. Create a new circuit.
3. Add an Arduino Uno and a Piezo Sensor.
4. Connect the sensor according to the circuit diagram.
5. Copy and paste the Arduino code.
6. Start the simulation.
7. Tap or vibrate the Piezo Sensor.
8. Observe the sensor values in the Serial Monitor.
