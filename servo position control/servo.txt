# Powerful Bigery-Bombul 🕹️⚡

A simple, interactive electronics simulation built in Tinkercad that demonstrates real-time hardware control using an Arduino Uno R3. 

This project reads analog data from a potentiometer (rotary knob) and translates it into physical movement via a micro servo motor.

## 📸 Circuit Layout

The system uses a standard 5V rail shared across a breadboard to power both the input sensor and the output actuator.

* **Project Name:** Powerful Bigery-Bombul (Tinkercad Generated)
* **Microcontroller:** Arduino Uno R3
* **Input:** $10\text{ k}\Omega$ Potentiometer
* **Output:** Micro Servo Motor (SG90)

## 🧠 How It Works

1. **Analog Input:** Turning the potentiometer changes the resistance, sending a variable voltage ($0\text{V}$ to $5\text{V}$) to the Arduino's Analog pin `A0`.
2. **Signal Processing:** The Arduino converts this analog voltage into a digital value ranging from `0` to `1023`.
3. **Mapping:** The code maps the input value proportionally down to a standard servo rotation angle between $0^\circ$ and $180^\circ$.
4. **PWM Output:** The Arduino outputs a Pulse Width Modulation (PWM) signal from Digital pin `9` to position the servo horn precisely.
