# 💡 Automatic Street Lighting using LDR Sensor and Arduino

## 📖 Project Description

This project demonstrates an Automatic Street Lighting System using an Arduino Uno, an LDR (Light Dependent Resistor), and an LED.

The LDR continuously measures the surrounding light intensity. When the environment becomes dark, the Arduino automatically turns ON the LED, simulating a street light. When sufficient light is detected, the LED turns OFF automatically.

This project is a simple example of smart lighting and energy-saving automation.

---

## 🎯 Objectives

- Detect ambient light levels using an LDR sensor.
- Automatically control an LED based on light intensity.
- Reduce energy consumption through automatic switching.
- Understand analog sensor interfacing with Arduino.

## ⚙️ Working Principle

1. The LDR senses the surrounding light intensity.
2. Arduino reads the analog value from pin A0.
3. When the light intensity decreases (dark condition):
   - LED turns ON.
4. When the light intensity increases (bright condition):
   - LED turns OFF.
5. This mimics the operation of an automatic street lighting system.

---

## 💻 Arduino Code

```cpp
const int ldrPin = A0;
const int ledPin = 8;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {

  int ldrValue = analogRead(ldrPin);

  Serial.print("LDR Value: ");
  Serial.println(ldrValue);

  if (ldrValue < 500) {
    digitalWrite(ledPin, HIGH);
  }
  else {
    digitalWrite(ledPin, LOW);
  }

  delay(100);
}
```
