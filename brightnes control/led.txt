# 💡 LED Brightness Control using Potentiometer and Arduino

## 📖 Project Description

This project demonstrates LED Brightness Control using an Arduino Uno, a Potentiometer, and an LED.

The potentiometer acts as an analog input device. As the knob is rotated, the Arduino reads the varying voltage and adjusts the LED brightness using Pulse Width Modulation (PWM). This allows smooth control of the LED intensity from OFF to fully ON.

This project is an excellent introduction to analog inputs and PWM outputs in Arduino.

---

## 🎯 Objectives

- Read analog values using a potentiometer.
- Control LED brightness using PWM.

## ⚙️ Working Principle

1. The potentiometer generates a variable voltage between 0V and 5V.
2. Arduino reads this voltage through analog pin A0.
3. The analog value ranges from 0 to 1023.
4. Arduino converts this value to a PWM range of 0 to 255.
5. The PWM signal is sent to pin D9.
6. LED brightness changes smoothly according to the potentiometer position.

---

## 💻 Arduino Code

```cpp
const int potPin = A0;
const int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {

  int potValue = analogRead(potPin);

  int brightness = map(potValue, 0, 1023, 0, 255);

  analogWrite(ledPin, brightness);

  delay(10);
}
```
