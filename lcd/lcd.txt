# Arduino Uno 16x2 LCD Character Display Interface

A Tinkercad-simulated physical computing project demonstrating how to interface a standard **16x2 Liquid Crystal Display (LCD)** with an Arduino Uno using parallel data bus communication.

## 📌 Project Overview
A 16x2 LCD can display up to 32 alphanumeric characters at once across two rows of 16 blocks. It relies on the industry-standard Hitachi HD44780 driver protocol. 

To maximize remaining microcontroller inputs for other peripheral tasks, this circuit implements the display in **4-bit mode**. Instead of sending data across 8 distinct pins, communication is serialized across 4 high-order data lines, saving four valuable digital input/output (GPIO) channels on the Arduino.

---

## 🛠️ Circuit Anatomy & Component List

The project leverages a half-size breadboard layout to organize power distributions, backlight protection, and control signal loops:

| Component | Quantity | Purpose |
| :--- | :--- | :--- |
| **Arduino Uno R3** | 1 | Microcontroller processing unit |
| **16x2 Character LCD** | 1 | Alphanumeric visual display screen panel |
| **Resistor ($220\Omega$)** | 1 | Current-limiting backlight protective resistor |
| **Half-Size Breadboard**| 1 | Component mounting platform |
| **Jumper Wires** | Mixed | Signal pathways and power rail buses |

### ⚡ Hardware Wiring Configuration

The layout organizes the standard 16-pin LCD header into specific operational groups:

1. **Power and Ground Infrastructure:**
   * Arduino **5V** $\rightarrow$ Breadboard Bottom Positive Rail (`+`) [Red Wire]
   * Arduino **GND** $\rightarrow$ Breadboard Bottom Negative Rail (`-`) [Black Wire]
   * *Cross-over links* pull common 5V and ground buses to the upper breadboard power rails.
   * **LCD VSS (GND - Pin 1):** Tied to common ground rail (Red wire on upper strip).
   * **LCD VCC (5V - Pin 2):** Tied to positive power rail (Red wire on upper strip).
   * **LCD V0 (Contrast - Pin 3):** Tied straight to Ground (Red wire on upper strip) for default maximum solid pixel contrast.
   * **LCD RW (Read/Write - Pin 5):** Tied directly to ground to keep the panel permanently in **Write** mode.

2. **Control Lines:**
   * **LCD RS (Register Select - Pin 4):** Connected to Arduino **Digital Pin 12** [Green Wire].
   * **LCD E (Enable - Pin 6):** Connected to Arduino **Digital Pin 11** [Green Wire].

3. **4-Bit Parallel Data Bus:**
   * **LCD DB4 (Pin 11):** Connected to Arduino **Digital Pin 5** [Green Wire].
   * **LCD DB5 (Pin 12):** Connected to Arduino **Digital Pin 4** [Green Wire].
   * **LCD DB6 (Pin 13):** Connected to Arduino **Digital Pin 3** [Green Wire].
   * **LCD DB7 (Pin 14):** Connected to Arduino **Digital Pin 2** [Green Wire].

4. **LED Backlight Control:**
   * **LCD LED Anode (Pin 15):** Connected to the positive rail through a $220\Omega$ current-limiting resistor to protect the backlight matrix from over-voltage.
   * **LCD LED Cathode (Pin 16):** Connected directly to the common ground rail.

## 💻 Source Code

The firmware below relies on the native `LiquidCrystal.h` library, handling the internal 4-bit timing sequences automatically.

```cpp
/**
 * 16x2 LCD Parallel Bus Interface Controller
 * Uses the LiquidCrystal library to print characters over a 4-bit bus.
 */

#include <LiquidCrystal.h>

// Initialize the library interface by mapping the control and data pins:
// LiquidCrystal(rs, enable, d4, d5, d6, d7)
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

void setup() {
  // Define the interface dimensions (16 columns and 2 rows)
  lcd.begin(16, 2);
  
  // Print a static message to the home position (Column 0, Row 0)
  lcd.print("Hello, GitHub!");
  
  // Adjust cursor position to the second row (Column 0, Row 1)
  lcd.setCursor(0, 1);
  lcd.print("LCD Circuit OK");
}

void loop() {
  // Static display loop - message remains persistent on screen
}
