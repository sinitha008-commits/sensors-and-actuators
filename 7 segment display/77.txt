# Arduino Uno 7-Segment Display Controller

A Tinkercad-simulated digital electronics project demonstrating how to interface a **single-digit 7-segment LED display** with an Arduino Uno. The circuit uses independent digital pins to control specific LED segments, allowing the display of numbers and characters through software logic.

## 📌 Project Overview
A 7-segment display consists of seven individual LEDs arranged in an "8" shape, plus an optional eighth LED for a decimal point (DP). By selectively turning these internal LEDs (segments $a$ through $g$) `HIGH` or `LOW`, the microcontroller can display numbers from `0` to `9`.

This project establishes the hardware pin-mapping matrix and provides the standard control array logic required to run counters or static number displays.

---

## 🛠️ Circuit Anatomy & Component List

The layout utilizes a direct pin-to-segment configuration with current-limiting resistors protecting the display elements:

| Component | Quantity | Purpose |
| :--- | :--- | :--- |
| **Arduino Uno R3** | 1 | Main microcontroller processing unit |
| **7-Segment Display** | 1 | Common Cathode (or Common Anode) visual display output |
| **Resistors ($330\Omega$)** | 2 | Current-limiting resistors protecting the shared common ground nodes |
| **Mini Breadboard** | 1 | Circuit routing platform |
| **Jumper Wires** | Mixed | Signal pathways bridging Arduino GPIO to segment pins |

### ⚡ Hardware Wiring Matrix

Based on the colorful routing paths in the Tinkercad workspace image, the pins are mapped as follows:

* **Ground Loop:** Two black wires link the Arduino **GND** pins through $330\Omega$ current-limiting resistors to the **Common (COM)** ground pins located at the top and bottom center of the 7-segment display.
* **Segment Signal Control Lines:**
  * Arduino **Pin 13** $\rightarrow$ Segment $a$ (Orange)
  * Arduino **Pin 12** $\rightarrow$ Segment $b$ (Yellow)
  * Arduino **Pin 11** $\rightarrow$ Segment $c$ (Cyan)
  * Arduino **Pin 10** $\rightarrow$ Segment $d$ (Blue)
  * Arduino **Pin 9** $\rightarrow$ Segment $e$ (Purple)
  * Arduino **Pin 8** $\rightarrow$ Segment $f$ (Magenta)
  * Arduino **Pin 7** $\rightarrow$ Segment $g$ (Brown)
  * Arduino **Pin 6** $\rightarrow$ Decimal Point / DP (Grey)
