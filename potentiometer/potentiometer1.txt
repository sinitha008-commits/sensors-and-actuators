# Potentiometer with Arduino (Tinkercad)

## Overview

This project demonstrates how to interface a potentiometer with an Arduino Uno in Tinkercad. A potentiometer is a variable resistor that allows users to adjust resistance manually. The Arduino reads the analog voltage from the potentiometer and displays the corresponding value on the Serial Monitor.

---

## Components Required

- Arduino Uno
- Potentiometer (10kΩ)
- Breadboard
- Jumper Wires
- Tinkercad Circuits

---

## Circuit Connections

| Potentiometer Pin | Connection |
|-------------------|------------|
| Left Pin | GND |
| Middle Pin (Wiper) | A0 |
| Right Pin | 5V |

### Connection Diagram

```
Potentiometer        Arduino Uno
--------------------------------
Left Pin     ------> GND
Middle Pin   ------> A0
Right Pin    ------> 5V
```

---

## Arduino Code

```cpp
const int potPin = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int sensorValue = analogRead(potPin);

  Serial.print("Potentiometer Value: ");
  Serial.println(sensorValue);

  delay(500);
}
```

---

## Working Principle

1. The potentiometer acts as a voltage divider.
2. Rotating the knob changes the output voltage.
3. Arduino reads this voltage through analog pin A0.
4. The analog value ranges from 0 to 1023.
5. The value is displayed on the Serial Monitor.
