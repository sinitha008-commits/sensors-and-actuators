# PIR Motion Sensor with Arduino (Tinkercad)

## Overview

This project demonstrates how to interface a PIR (Passive Infrared) Motion Sensor with an Arduino Uno in Tinkercad. The PIR sensor detects motion by sensing changes in infrared radiation emitted by objects such as humans and animals.

When motion is detected, the sensor outputs a HIGH signal. The Arduino reads this signal and displays the result on the Serial Monitor.

---

## Components Required

- Arduino Uno
- PIR Motion Sensor
- Breadboard
- Jumper Wires
- Tinkercad Circuits

---

## Circuit Connections

| PIR Sensor Pin | Arduino Connection |
|---------------|-------------------|
| VCC | 5V |
| OUT | Digital Pin 2 |
| GND | GND |

### Connection Diagram

```
PIR Sensor         Arduino Uno
--------------------------------
VCC      --------> 5V
OUT      --------> D2
GND      --------> GND
```

---

## Arduino Code

```cpp
int pir = 2;

void setup() {
  pinMode(pir, INPUT);
  Serial.begin(9600);
}

void loop() {
  Serial.println(digitalRead(pir));
  delay(500);
}
```

---

## Working Principle

1. The PIR sensor continuously monitors infrared radiation.
2. When a person or object moves within its detection range, the infrared pattern changes.
3. The sensor outputs a HIGH signal (1).
4. Arduino reads the signal through Digital Pin 2.
5. The result is displayed on the Serial Monitor.

## How to Run

1. Open Tinkercad Circuits.
2. Create a new circuit.
3. Add an Arduino Uno and a PIR Motion Sensor.
4. Connect the sensor according to the circuit diagram.
5. Copy and paste the Arduino code into the code editor.
6. Start the simulation.
7. Open the Serial Monitor.
8. Trigger the PIR sensor in Tinkercad to observe motion detection.
