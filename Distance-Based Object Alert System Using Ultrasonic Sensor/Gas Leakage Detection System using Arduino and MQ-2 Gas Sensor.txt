# 🚨 Gas Leakage Detection System using Arduino and MQ-2 Gas Sensor

## 📖 Project Description

This project implements a Gas Leakage Detection System using an Arduino Uno, an MQ-2 Gas Sensor, LEDs, and a buzzer.

The MQ-2 sensor continuously monitors the surrounding air for combustible gases and smoke. When the gas concentration exceeds a predefined threshold, the Arduino activates a buzzer and a red LED to alert users of a potential gas leak. Under normal conditions, a green LED remains ON to indicate safe operation.

This project is useful for home safety, industrial monitoring, and environmental protection.

---

## 🎯 Objectives

- Detect combustible gases and smoke using an MQ-2 sensor.
- Alert users using a buzzer when gas leakage is detected.
- Indicate system status using LEDs.
- Demonstrate sensor and actuator interfacing with Arduino.

## ⚙️ Working Principle

1. The MQ-2 sensor continuously measures gas concentration.
2. Arduino reads the analog value from pin A0.
3. If the gas level is below the threshold:
   - Green LED remains ON.
   - Red LED remains OFF.
   - Buzzer remains OFF.
4. If the gas level exceeds the threshold:
   - Red LED turns ON.
   - Green LED turns OFF.
   - Buzzer sounds an alarm.
5. The system continuously monitors the environment for safety.

## 💻 Arduino Code

```cpp
const int gasSensor = A0;
const int buzzer = 8;
const int redLED = 12;
const int greenLED = 10;

int threshold = 400;

void setup() {
  pinMode(buzzer, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(greenLED, OUTPUT);

  Serial.begin(9600);
}

void loop() {

  int gasValue = analogRead(gasSensor);

  Serial.print("Gas Value: ");
  Serial.println(gasValue);

  if (gasValue > threshold) {

    digitalWrite(redLED, HIGH);
    digitalWrite(greenLED, LOW);
    digitalWrite(buzzer, HIGH);

  } else {

    digitalWrite(redLED, LOW);
    digitalWrite(greenLED, HIGH);
    digitalWrite(buzzer, LOW);
  }

  delay(100);
}
```
